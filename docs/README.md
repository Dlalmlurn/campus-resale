# Documentation Index

本目录保存校园二手交易系统的项目文档。项目完成后的日常阅读优先从 `正式文档/` 开始；开发过程、阶段契约和原始材料统一归入 `历史资料/`。

## 阅读入口

| 目录 | 用途 |
| --- | --- |
| `正式文档/` | 项目长期口径：项目宪章、产品形态、领域契约、决策收束、质量标准和数据库设计。 |
| `开发指南/` | 面向开发联调的专题说明，例如审计 API 指南。 |
| `部署/` | 部署、运维和生产环境说明。 |
| `答辩/` | 演示台本、截图清单和验收清单。 |
| `adr/` | 少量长期架构决策记录，以及已吸收历史 ADR 的来源说明。 |
| `历史资料/` | 开发过程归档：阶段契约、项目进程记录和未纳入 git 的本地原始需求与设计材料。 |

## 正式文档

| 文档 | 职责 |
| --- | --- |
| `正式文档/00_project_baseline.md` | 项目宪章：定义项目使命、成功定义、目标能力、正式边界、架构选择、依赖版本基线、对象存储口径和 ADR 粒度。 |
| `正式文档/01_project_shape.md` | 产品目标形态：定义产品入口、用户旅程、页面地图、关键页面目标和后台形态。 |
| `正式文档/02_domain_contracts.md` | 领域契约：定义角色权限、领域对象、事件、接口族和一致性规则。 |
| `正式文档/03_decision_backlog.md` | 决策收束记录：说明已访谈问题的收束状态和后续 ADR 粒度规则。 |
| `正式文档/04_final_quality_criteria.md` | 最终质量标准：定义系统达到目标形态时应满足的检查项。 |
| `正式文档/05_database_design.md` | 数据库设计：定义表分组、关键字段、状态枚举、约束索引、统计视图和迁移顺序。 |

## 维护规则

- 后续补充优先修改 `正式文档/` 中已有编号文档的对应章节。
- 单个问题、单条规则、单次访谈结论不新增根目录文件。
- 新增正式编号文档只用于新的稳定专题，例如独立的安全基线、运维基线或外部系统接入基线。
- 新增 ADR 只用于存在长期分叉且会影响架构边界的选择。
- `历史资料/` 只提供背景依据；若与正式文档冲突，以 `正式文档/` 为准。
