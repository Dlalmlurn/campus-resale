# 验收清单

按阶段勾选，用于答辩自检与现场逐项验收。每条都能在演示环境点击或调用复现。

## M0 工程底座
- [ ] `docker compose up --build` 一键起前端/后端/PostgreSQL/MinIO。
- [ ] `GET /api/health` 与 `/actuator/health` 返回健康。
- [ ] `./scripts/check.sh` 后端测试 + 前端测试 + 前端构建全绿。

## M1 认证 + 商品 MVP
- [ ] 注册、登录、退出、`/api/auth/me` 正常；登录态走 `CR_SESSION` HttpOnly Cookie。
- [ ] 普通用户提交校园认证；管理员审核通过后获得交易资格。
- [ ] 认证学生发布商品草稿 → 提交审核 → 管理员通过 → 进入公开列表。
- [ ] 公开商品支持详情查看与关键词/分类搜索。
- [ ] 未登录/未认证用户访问受保护操作被正确拦截。

## N1 最小交易闭环
- [ ] 商品详情下单，`SELECT ... FOR UPDATE` 占用商品避免超卖。
- [ ] 卖家确认 → 买家模拟支付（资金托管）→ 双方完成确认 → 订单 COMPLETED。
- [ ] 结算状态推进；买家提交最小评价。
- [ ] 会话发送消息与议价卡片，WebSocket 实时到达。
- [ ] 订单各关键节点写入站内通知。

## N2 后台验收闭环
- [ ] 管理员数据看板：订单/支付/结算统计。
- [ ] 认证、商品审核队列可操作。
- [ ] 审计日志可追溯关键操作（含 AI 辅助、敏感访问）。
- [ ] 资金后台入口可查看结算与退款。

## N3 治理闭环
- [ ] 举报（商品/订单）+ 证据上传；管理员裁决，举报成立联动下架/订单关闭/信用扣减/处罚。
- [ ] 申诉提交与通过，反向修正处罚与信用。
- [ ] 退款状态推进；治理动作写站内通知。
- [ ] 信用摘要聚合对外标签与内部等级。
- [ ] 处罚 `TRADE_RESTRICT`/`ACCOUNT_LOCK` 联动交易资格拦截主链路。

## N4 AI + 发现增强
- [ ] AI 发布辅助生成标题/描述/分类/标签/风险/推荐理由，并写 `ai_assist_records` 与审计日志。
- [ ] 频率限制（默认每人每天 5 次）生效。
- [ ] 高风险词触发 `AI_REVIEW_REMINDER` 通知；AI 不自动审核/下架/处罚。
- [ ] **规则风险兜底**：即使 LLM 判低风险，命中高风险词仍按 HIGH 提示（不可被 LLM 降级）。
- [ ] 建议面板显示来源徽章（规则引擎 / AI 模型生成）。
- [ ] 发现页 `RECOMMENDED` 排序 + 推荐理由；卡片可直接收藏商品、关注卖家。

## 收尾：测试 / 数据 / 部署 / 答辩
- [ ] 后端单元测试全绿（含 AI 规则/LLM 融合/风险兜底、Cookie Secure）。

- [ ] 演示种子齐全：`seller_demo`/`buyer_demo` 已认证且 seller_demo 有在售商品，买卖闭环可直接演示。
