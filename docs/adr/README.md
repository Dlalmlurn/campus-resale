# ADR 说明

ADR 是 Architecture Decision Record，也就是架构决策记录。

本项目不再为每个业务细则单独创建 ADR。ADR 只记录少数会长期影响系统结构的分叉决策；普通规则进入项目宪章、产品形态、领域契约、接口说明或开发设计。

## 新增 ADR 规则

只有当问题满足以下条件之一时，才新增 ADR：

- 改变正式技术栈、部署形态或主数据链路。
- 改变核心状态机、资金链路、治理链路或 AI 使用边界。
- 引入新的核心领域对象、外部服务或跨模块一致性约束。
- 推翻或替代项目宪章或领域契约中的长期口径。

以下内容不单独创建 ADR：

- 单个字段名、接口路径、页面交互、提示文案、按钮位置。
- 已能从正式编号文档推导出的业务规则。
- 局部校验顺序、查询细节、定时任务实现方式。

这类内容应进入开发设计、接口说明、代码实现或测试用例。
