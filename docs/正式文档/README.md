# 正式文档

本目录保存项目长期稳定口径。日常开发、答辩和部署说明若出现冲突，以这里的编号文档为准。

## 阅读顺序

| 文档 | 内容 |
| --- | --- |
| `00_project_baseline.md` | 项目宪章、边界、技术选择和长期决策。 |
| `01_project_shape.md` | 产品入口、用户旅程、页面地图和后台形态。 |
| `02_domain_contracts.md` | 角色权限、领域对象、接口族、事件和一致性规则。 |
| `03_decision_backlog.md` | 已收束决策与后续 ADR 粒度规则。 |
| `04_final_quality_criteria.md` | 最终质量标准和验收检查项。 |
| `05_database_design.md` | 数据库表分组、关键字段、状态枚举、约束索引和迁移顺序。 |
